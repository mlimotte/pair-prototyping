Coding agents make code cheap. A team that writes code twice as fast does not ship twice as much product. It runs out of good things to build. The backlog becomes the constraint.

This series is about filling the backlog with good items. Its method is old: build a small thing, look at it, decide, and repeat. What is new is the cost. An agent builds a prototype in an hour, against real data, so the loop can run on each backlog item.

The series is for engineers first. In the loop, the engineer is the person whose agent can see the architecture and the data. Product people are the second audience: parts 1 to 3 need no code.

All the examples happen at Brew Board, the ordering app of a small coffee company with three stores. Morgan owns the product, and Sam runs the counter at Pearl Street. Brew Board is the setting, not the subject. You do not build it. Your agent reads it, queries its data and changes it.
