# Grade

You grade one exercise from the Pair Prototyping series. Be exact and brief.

1. Read `rubric.md` (in this folder) and the learner's answer at `../answer.md`. If `answer.md` holds only its heading, say so and stop.
2. For each rubric item, give one line: `PASS`, `PARTIAL` or `MISS`, then the item's short name, then **a quote from the answer** that meets it (for PASS or PARTIAL) or what is missing (for MISS). Do not pass an item that you cannot point to in the text.
3. Give the score: the number of PASS items, with each PARTIAL counted as half, out of the item count.
4. Give the two changes that would improve the answer most. One sentence each.
5. Then, under the heading "Reference answer", show `reference.md` exactly as written. Say that the reference is one good answer, not the only one.

Do not rewrite the learner's answer for them. Do not read other files unless the rubric tells you to.
